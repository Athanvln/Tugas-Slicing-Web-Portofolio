Deskripsi Proyek
Proyek ini adalah pembuatan dan slicing halaman Web Portofolio Personal interaktif yang dibangun murni menggunakan HTML5, Plain CSS3, serta JavaScript untuk manipulasiDOM. Website ini dirancang fully responsive agar nyaman diakses dari berbagai ukuran layar (mobile, tablet, dan desktop).

Fitur-Fitur Utama Website

1. Header & Navigation :
   * Navigasi melayang dengan efek *backdrop blur.
   * otomatis yang menandai menu aktif secara real-time saat di-scroll.
   * Menu interaktif khusus untuk tampilan layar mobile.

2. Hero / Home Section:
   * Salam pembuka personal, nama lengkap, status mahasiswa, dan deskripsi singkat.
   * Tautan ikon jejaring sosial (GitHub, LinkedIn, Instagram) yang interaktif saat di-hover.

3. Theme Toggle (Dark & Light Mode):
   * Sakelar ganti tema Dark/Light Mode murni menggunakan variabel CSS dan manipulasi atribut DOM JavaScript.

4. Skills & Tools Display:
   * Tampilan kategori keahlian (Programming Languages, Frontend, *Database*, Tools) dengan indikator titik.

5. Personal Project Showcase:
   * Kartu portofolio dengan efek overlay dan tombol navigasi cepat ke bagian atas/home.

6. Education Timeline:
   * Linimasa vertikal riwayat pendidikan formal dari SD (2012–2018), SMP (2018–2021), SMA (2021–2024), hingga S1 Informatika UNEJ (2025–Sekarang).

7. Interactive Contact Form & Social Cards:
   * Kartu kontak langsung ke media sosial & email.
   * Formulir kontak dengan validasi input DOM dan Toast Notification otomatis saat pesan dikirim.

8. Footer Responsif:
   * Kaki halaman yang memuat hak cipta, navigasi tautan cepat, dan icon sosial melingkar.
